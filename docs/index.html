AuditTrack

Welcome to AuditTrack

AuditTrack, powered by the Maintel Application Platform (MAP), is a secure, resilient, and compliant solution for long-term audit log storage. Designed to help organisations meet regulatory and governance requirements, AuditTrack allows the automatic export, archiving, and retrieval of audit logs and associated metadata from platforms such as Genesys Cloud.

Key Features

  • Automatic export and archiving of audit logs and metadata
  • Search and filter functionality across archived audit events
  • Secure storage with encryption at rest and in transit
  • SSO integration using Microsoft Entra (Azure AD)
  • Role-based access control and access audit logging
  • Fully managed service with subscription-based pricing
