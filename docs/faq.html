FAQ - AuditTrack

AuditTrack

What is AuditTrack?

AuditTrack is a secure, cloud-based audit log storage solution provided by Maintel. It enables automatic export and archiving of audit logs and metadata from supported platforms like Genesys Cloud, ensuring regulatory compliance and long-term data retention.

Which platforms does AuditTrack support?

AuditTrack currently supports Genesys Cloud. Additional integrations with other platforms are on the roadmap.

How secure is the storage of audit logs?

AuditTrack prioritises security with:

  • Encryption at rest (AWS S3 Managed Keys - SSE-S3)
  • Encryption in transit (TLS 1.3)
  • Audit logging of user access and activity
  • Role-based access and Single Sign-On (SSO) using Microsoft Entra

Is AuditTrack compliant with GDPR requirements?

Yes, AuditTrack is designed to support compliance with GDPR and wider regulatory requirements. GDPR-related data deletion requests can be submitted via Maintel's support process.

Can I search and filter audit logs?

Yes, the AuditTrack user interface allows you to search audit logs by:

  • Date
  • User
  • Service
  • Action

Audit event details can be viewed directly in the interface. Export functions are planned for future releases.

What happens if we exceed our storage limit?

Storage capacity is capped according to your selected package. If your storage usage exceeds the cap, you will move into the next pricing bracket as defined in your subscription agreement. Alerts and monitoring are in place to notify of capacity thresholds.

How is the service priced?

AuditTrack is offered as a subscription service on a Per User Per Month (PUPM) basis. Please contact Maintel for details of available packages and bespoke configurations.

How do I request deletion of audit data under GDPR?

To request deletion of audit data, contact Maintel support. A formal process will be followed, working with your organisation's representatives to confirm the request and obtain necessary authorisations.
