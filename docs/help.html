Help Guide - AuditTrack

AuditTrack

What is AuditTrack?

AuditTrack, powered by the Maintel Application Platform (MAP), provides secure, long-term storage for audit logs and metadata from cloud-based contact centre platforms such as Genesys Cloud. It helps customers meet regulatory and governance requirements and retain valuable audit data for compliance and investigation purposes.

Key Features and Benefits

  • Compliant, long-term audit log storage
  • Search and filter functionality across archived audit events
  • Retention of audit data beyond vendor-imposed time limits
  • Secure AWS-based storage with encryption at rest and in transit
  • Role-based access and Single Sign-On (SSO) via Microsoft Entra
  • Ongoing platform monitoring and alerting

How AuditTrack Works

AuditTrack integrates with contact centre platforms to automatically export and archive audit logs and associated metadata into a secure AWS S3 environment. The solution includes:

  • Authentication and Authorisation Module
  • Secrets Management
  • Genesys API Integration
  • Audit Log Retrieval API
  • Searchable User Interface built on React

Security and Compliance

AuditTrack is designed with security at its core:

  • Encryption at rest using AWS S3 Managed Keys (SSE-S3)
  • Encryption in transit using HTTPS (TLS 1.3)
  • Audit logging of user access and actions
  • GDPR-compliant data deletion process via Maintel support tickets
  • Penetration testing options available

Supported Platforms

Currently supported: Genesys Cloud
Further integrations are on the roadmap.

Accessing and Using the AuditTrack UI

The AuditTrack User Interface allows you to:

  • Log in securely with your corporate SSO credentials
  • Search audit logs by date, user, service, and action
  • View audit event details directly in the interface
  • Export audit data (roadmap feature)
  • Manage admin users and roles (roadmap feature)

Pricing and Packages Overview

AuditTrack is available as a subscription service with Per User Per Month (PUPM) pricing. Please contact Maintel for details of available packages and bespoke configurations.
